# FitAI 智能健身助手 - 设计风格指南

## 气质与意象

**关键词**：活力、专业、简洁、科技感、温暖

**具象场景**：
清晨阳光透过落地窗洒进健身房，空气中漂浮着微尘。智能手表在手腕上轻轻震动，显示着今日的卡路里目标。手机屏幕上，一张刚拍摄的食物照片被 AI 瞬间识别，营养成分清晰呈现。训练计划如同私人教练般，精准推送今日的锻炼方案。

## 视觉策略

- **摄影/图像方向**：明亮、高对比度的健身场景照片；食物图片采用自然光线，突出食材真实质感
- **图形语言**：圆润的卡片边角，柔和的阴影过渡，流畅的动画曲线
- **图标风格**：Lucide 线性图标，简洁现代，与整体设计融为一体

## 配色方案

| 色彩角色 | Tailwind 类名 | 色值 | 意象来源 |
|---------|-------------|------|---------|
| 主色（活力橙） | `bg-orange-500` / `text-orange-500` | #f97316 | 运动后的汗水与能量 |
| 辅色（健康绿） | `bg-emerald-500` / `text-emerald-500` | #10b981 | 新鲜蔬果、健康指标达标 |
| 强调色（科技蓝） | `bg-blue-500` / `text-blue-500` | #3b82f6 | AI 智能分析、数据可视化 |
| 背景色 | `bg-gray-50` / `bg-white` | #f9fafb / #ffffff | 干净的训练环境 |
| 文字主色 | `text-gray-900` | #111827 | 专业、清晰的信息传递 |
| 文字辅色 | `text-gray-500` | #6b7280 | 补充说明、次要信息 |
| 卡片背景 | `bg-white` | #ffffff | 清爽的信息卡片 |
| 成功/正向 | `bg-emerald-100` / `text-emerald-700` | - | 热量达标、计划完成 |
| 警告/提醒 | `bg-amber-100` / `text-amber-700` | - | 热量超标提醒 |

## 字体排版

- **推荐字体**：系统默认字体栈（-apple-system, "PingFang SC", "Helvetica Neue"）
- **H1 标题**：`text-2xl font-bold text-gray-900` - 页面主标题
- **H2 标题**：`text-xl font-semibold text-gray-800` - 模块标题
- **H3 小标题**：`text-lg font-medium text-gray-700` - 卡片标题
- **正文**：`text-base text-gray-600` - 主要内容
- **辅助文字**：`text-sm text-gray-500` - 说明文字、时间戳
- **数据展示**：`text-3xl font-bold text-orange-500` - 热量数值等关键数据

## 间距系统

- **页面边距**：`p-4` (16px)
- **卡片内边距**：`p-4` / `p-5`
- **组件间距**：`gap-3` / `gap-4`
- **列表项间距**：`gap-2` / `gap-3`
- **底部安全区**：`pb-20`（避开 TabBar）

## 组件使用原则

**必须优先使用 `@/components/ui/*` 组件库**：

| UI 单元 | 组件库组件 | 使用场景 |
|--------|----------|---------|
| 按钮 | `Button` | 上传图片、发送消息、生成计划、保存等操作 |
| 输入框 | `Input` | 文字对话输入、补充食物信息 |
| 卡片 | `Card` | 食物识别结果展示、训练计划卡片、统计数据展示 |
| 标签 | `Badge` | 食物类型标签、训练强度标签、热量状态标签 |
| 对话列表 | `Card` + 自定义布局 | 对话消息展示 |
| 进度条 | `Progress` | 热量摄入进度、训练完成度 |
| 标签页 | `Tabs` | 今日摄入 / 训练计划 切换（首页） |
| 弹窗 | `Dialog` | 训练计划详情、编辑弹窗 |
| 分割线 | `Separator` | 内容区块分隔 |
| 空状态 | 自定义 `View` + `Text` | 无训练计划时的提示 |
| 加载态 | `Skeleton` | AI 分析中的加载提示 |

**禁止用 `View/Text` 手搓**：Button、Input、Card、Badge、Tabs、Dialog、Progress 等通用组件的外观与交互。

## 导航结构

**TabBar 配置**：
1. **热量计算** (`pages/index/index`) - 图标: `Flame`
2. **训练计划** (`pages/training/index`) - 图标: `Dumbbell`
3. **我的** (`pages/profile/index`) - 图标: `User`

**TabBar 风格**：
- `color: #999999`（未选中）
- `selectedColor: #f97316`（选中，活力橙）
- `backgroundColor: #ffffff`

## 页面结构

### 首页（热量计算）

**区域划分**：
1. **顶部统计卡片**：今日热量摄入进度（Progress + 数值展示）
2. **功能入口区**：上传食物图片按钮 + 文字对话入口
3. **对话展示区**：AI 对话记录列表（可滚动）
4. **识别结果卡片**：当前食物识别结果（食物名、分量、热量、营养成分）

### 训练计划页

**区域划分**：
1. **生成入口**：基于热量需求生成个性化计划按钮
2. **计划列表**：已保存的训练计划卡片列表
3. **计划详情**：点击卡片进入详情弹窗（训练内容、时长、强度）

### 我的页

**区域划分**：
1. **用户信息卡片**：头像、昵称、基础信息
2. **设置项列表**：个人信息设置、目标设置等

## 动效与交互

- **运动性格**：轻快、流畅，体现活力感
- **缓动曲线**：`ease-out`，自然过渡
- **悬停反馈**：按钮轻微缩放 + 阴影变化
- **卡片展开**：从中心向四周展开动画
- **加载动画**：骨架屏渐变闪烁

## 设计禁忌

- ❌ 禁止使用深色背景（健身场景需要明亮感）
- ❌ 禁止使用过多颜色堆砌（保持清爽）
- ❌ 禁止使用尖锐边角（圆润更亲和）
- ❌ 禁止复杂的数据图表（简洁数值展示为主）
- ❌ 禁止小字号信息堆叠（保证可读性）
- ❌ 禁止 TabBar 图标使用 base64/SVG（必须本地 PNG）

## 小程序约束

- **主包体积**：≤ 2MB
- **图片策略**：用户上传图片存 TOS，代码中用 URL 引用；TabBar 图标本地 PNG
- **性能优化**：图片懒加载、虚拟列表（训练计划列表）
