# 健身搭子 · UI 设计说明文档（iOS 27 / Liquid Glass）

> 本文档面向 UI 设计师，用于产出高保真设计稿。所有交互、间距、配色、动效均有明确规定，请严格遵守。

---

## 0. 项目背景

**产品名**：健身搭子（小程序）
**目标用户**：减脂 / 增肌 / 塑形人群
**核心价值**：饮食记录 + 训练打卡 + AI 教练 + 个人数据可视化
**设备**：微信小程序（iOS 渲染层），按 iPhone 14 / 15 / 16 设计稿尺寸（750 × 1624 基准，2x 出图）
**设计基准**：iOS 26/27 Human Interface Guidelines（Liquid Glass 液态玻璃）
**设计稿尺寸**：375 × 812 pt（最终） / 750 × 1624 px（2x）

---

## 1. 设计语言

### 1.1 关键词
- **Liquid Glass**：液态玻璃 — 半透明、模糊、轻微折射
- **Inset Grouped**：嵌入式分组列表（圆角更大，分组间有间距）
- **Large Title**：大标题导航（页面顶部，72pt 字号）
- **Spring Motion**：弹簧动效（不是直线 ease）
- **Tabular Numerics**：数字等宽（卡路里等数据对齐）

### 1.2 三大主色

| 角色 | 名称 | Light | Dark |
| --- | --- | --- | --- |
| 背景 | systemGroupedBackground | `#F2F2F7` | `#000000` |
| 卡片 | secondarySystemGroupedBackground | `#FFFFFF` | `#1C1C1E` |
| 主色 | systemBlue | `#007AFF` | `#0A84FF` |

### 1.3 系统色（用于图标徽章、按钮、标签）

| 名称 | Light | Dark | 用途 |
| --- | --- | --- | --- |
| systemBlue | `#007AFF` | `#0A84FF` | 主色 / 链接 / 饮食 |
| systemGreen | `#34C759` | `#30D158` | 训练 / 完成 / 增肌 |
| systemOrange | `#FF9500` | `#FF9F0A` | 警告 / 接近上限 |
| systemRed | `#FF3B30` | `#FF453A` | 删除 / 危险 / 退出 |
| systemPurple | `#AF52DE` | `#BF5AF2` | AI / 高亮 |
| systemIndigo | `#5856D6` | `#5E5CE6` | 次要强调 |
| systemMint | `#00C7BE` | `#66D4CF` | 装饰 |
| systemTeal | `#5AC8FA` | `#64D2FF` | 数据可视化 |

### 1.4 语义 Tint 背景（iOS HIG 风格）

| 名称 | 背景 | 前景 | 用途 |
| --- | --- | --- | --- |
| tintBlue | `rgba(0,122,255,0.08)` | `#007AFF` | 链接按钮、提示 |

| tintPurple | `rgba(175,82,222,0.12)` | `#6E2D9C` | AI、个性化 |

### 1.5 文本分级（HIG Label Colors）

| 级别 | Light | Dark | 用途 |
| --- | --- | --- | --- |
| labelPrimary | `#000000` | `#FFFFFF` | 主标题、关键数字 |
| labelSecondary | `rgba(60,60,67,0.78)` | `rgba(235,235,245,0.78)` | 副标题、说明 |
| labelTertiary | `rgba(60,60,67,0.55)` | `rgba(235,235,245,0.55)` | 辅助、单位 |
| labelQuaternary | `rgba(60,60,67,0.32)` | `rgba(235,235,245,0.32)` | 占位、禁用 |

### 1.6 分割线
- 默认：`rgba(60, 60, 67, 0.10)`（半透明，融入背景）
- 加重：`rgba(60, 60, 67, 0.18)`
- 不透明：仅在深色模式下用 `#38383A`

## 2. 字体（SF Pro 体系）

### 2.1 字体栈
```
-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display",
"PingFang SC", "Helvetica Neue", sans-serif
```
- 数字统一开启 `font-variant-numeric: tabular-nums`（等宽对齐）
- 全部开启 `-webkit-font-smoothing: antialiased`

### 2.2 字阶（以 750px 设计稿为基准，单位 rpx，1px = 2rpx）

| 用途 | rpx | pt 换算 | 字重 | 字距 |
| --- | --- | --- | --- | --- |
| largeTitle 页面大标题 | 72 | 36pt | 800 | -2 |
| title 1 卡片大标题 | 48 | 24pt | 700 | -1 |
| title 2 章节大数字 | 40 | 20pt | 700 | -0.5 |
| title 3 | 36 | 18pt | 700 | 0 |
| headline 列表主标题 | 30 | 15pt | 600 | -0.3 |
| body 正文 | 28 | 14pt | 400 | 0 |
| callout | 30 | 15pt | 500 | 0 |
| subhead 副标题 | 26 | 13pt | 400 | 0 |
| footnote | 24 | 12pt | 400 | 0 |
| caption 2 | 22 | 11pt | 500 | 0 |
| caption 1 | 20 | 10pt | 500 | 0 |
| section header | 22 | 11pt | 600 | +2（uppercase） |

> 数字（卡路里、克数）：用 SF Pro Rounded 或 SF Pro Display，weight 700-800，开启 tabular-nums

## 3. 间距与圆角

### 3.1 间距阶梯（8 倍数）
| 名称 | rpx | px |
| --- | --- | --- |
| xs | 8 | 4 |
| sm | 16 | 8 |
| md | 24 | 12 |
| lg | 32 | 16 |
| xl | 48 | 24 |
| 2xl | 64 | 32 |

### 3.2 页面外边距
- 页面水平内边距：**32 rpx（16pt）**
- 卡片之间纵向间距：**24 rpx（12pt）**

### 3.3 圆角（iOS 27 关键 — 比 iOS 14 大）
| 名称 | rpx | 用途 |
| --- | --- | --- |
| ui | 24 | 按钮、输入框、徽章 |
| card | 32 | 普通卡片、Inset Card |
| grouped | 28 | Inset Grouped Card（首选） |
| hero | 36 | Hero Card（首页能量环卡） |
| ring | 999 | 完全圆角 |
| bubble | 28 (角：8 尖角) | 聊天气泡 |

### 3.4 阴影（柔和、偏暖）
| 名称 | 用途 | 参数 |
| --- | --- | --- |
| shadow-xs | 列表分隔 | `0 1rpx 2rpx rgba(0,0,0,0.04)` |
| shadow-sm | 卡片 | `0 4rpx 16rpx rgba(0,0,0,0.06)` |
| shadow-md | Hero 卡 | `0 12rpx 32rpx rgba(0,0,0,0.08)` |
| shadow-lg | 弹层 | `0 24rpx 56rpx rgba(0,0,0,0.12)` |
| shadow-glass | 液态玻璃 | `0 8rpx 32rpx rgba(0,0,0,0.08), 0 0 0 0.5rpx rgba(255,255,255,0.6) inset` |

### 4.2 关键组件详细规范

#### Primary Button
```
高 88rpx | 圆角 28rpx | 字号 30rpx / 600
背景：systemBlue
阴影：0 6rpx 16rpx rgba(0,122,255,0.28)
按下：scale(0.97) + 阴影减弱（spring 200ms）
内边距：左右 32rpx 页面外边距对齐
```

#### Inset Grouped Card
```
页面内边距 32rpx
背景：#FFFFFF (Light) / #1C1C1E (Dark)
圆角 28rpx
阴影 shadow-xs
内部 List Row 之间使用半透明分割线（左 28rpx 缩进）
```

#### List Row
```
最小高度 96rpx
padding: 16rpx 28rpx
:active → 背景 fill-quaternary 闪一下
:bottom 半透明分割线（最后一根隐藏）
可选：左侧 60×60 ListIcon + 主标题 + 副标题 + value + chevron
```

#### Progress Bar
```
高 12rpx
背景 fill-tertiary
fill 圆角 999，width 过渡 500ms ease-out
fill 颜色：blue/green/orange/red/purple
```

#### Energy Ring
```
SVG viewBox 200×200
外圈 r=86, stroke-width=14
背景圆 stroke=fill-tertiary
进度圆 stroke=systemBlue
进度 ≥100% 变红，≥80% 变橙
linecap: round
transform: rotate(-90deg)
中心：超大字号 80rpx / 800
```

#### Tab Bar
```
宽度 590rpx | 高度 104rpx | 圆角 52rpx
背景：rgba(247,247,249,0.96)
backdrop-filter: blur(28px) saturate(180%)
阴影：0 18rpx 48rpx rgba(0,0,0,0.13)
5 个 tab：首页 / 饮食 / AI 教练 / 训练 / 我的
中间 AI tab 用 sparkle 渐变图标
选中态：圆角 44rpx 蓝底 10% 透明 + 蓝字
```

## 7. 动效规范

### 7.1 缓动函数
- **standard**: `cubic-bezier(0.25, 0.1, 0.25, 1)` — 默认
- **decelerate**: `cubic-bezier(0.22, 1, 0.36, 1)` — 入场
- **accelerate**: `cubic-bezier(0.64, 0, 0.78, 0)` — 退场
- **spring**: `cubic-bezier(0.34, 1.56, 0.64, 1)` — 弹性回弹
- **bouncy**: `cubic-bezier(0.5, 1.5, 0.5, 1)` — 强调

### 7.2 时长
- 快速（按钮反馈）：200ms
- 普通（页面切换）：300-350ms
- 慢速（弹层入场）：500ms
- Rest Timer 脉冲：1000ms infinite

### 7.3 关键动效

| 场景 | 效果 |
| --- | --- |
| 按钮按下 | scale(0.96-0.98) spring 200ms |
| 卡片入场 | translateY(16rpx) + opacity 350ms，错峰 60-80ms |
| 模态弹出 | scale(0.95→1) + opacity 500ms spring |
| 列表展开 | max-height + opacity 350ms decelerate |
| 能量环进度 | stroke-dashoffset 500ms ease-out |
| 任务完成 | scale(1.0→1.2→1.0) spring + 颜色切换 |
| Rest Timer 入场 | translateY(20rpx) + opacity 350ms spring |
| Tab 切换 | iOS 系统级 250ms |
| 弹层退场 | scale(1→0.95) + opacity 200ms accelerate |

### 7.4 触觉反馈
- 按钮点击：`wx.vibrateShort({type:'light'})` 10ms
- 训练组完成：`wx.vibrateShort({type:'medium'})` 15ms
- 休息结束：`wx.vibrateLong()` 400ms
- AI 错误：双击短振 20ms × 2

## 8. 暗色模式

### 8.1 规则
- 全部使用 `@media (prefers-color-scheme: dark)` 自动切换
- 关键 token：
  - 背景：`#F2F2F7` → `#000000`
  - 卡片：`#FFFFFF` → `#1C1C1E`
  - 提升卡：`#FFFFFF` → `#2C2C2E`
  - 主色蓝：`#007AFF` → `#0A84FF`（更亮）
  - 绿：`#34C759` → `#30D158`
  - 红：`#FF3B30` → `#FF453A`

### 8.2 暗色专属调整
- 主背景纯黑（不是深灰），省电 + OLED 友好
- 阴影全部加深：`shadow-sm` 从 `rgba(0,0,0,0.06)` → `rgba(0,0,0,0.32)`
- 分割线不透明度提高：`0.10` → `0.30`
- Tinted background 透明度提高：`0.08` → `0.18`
- 头像背景渐变反向：`#576171 → #242A32` 改为 `#2C2C2E → #1C1C1E`

## 9. 可达性 (Accessibility)

- 全部可点击元素最小尺寸 **88 × 88 rpx**（44 × 44pt）
- 全部交互元素必须带 `aria-label`（中英文）
- 文字与背景对比度 ≥ 4.5:1（labelSecondary 已满足）
- 不依赖纯颜色传递信息（图标 + 文字 + 颜色）
- 动态字号：尊重系统字号设置，关键数字使用相对单位
