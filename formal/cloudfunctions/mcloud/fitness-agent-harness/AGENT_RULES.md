# Agent Rules

1. 只支持饮食记录、饮食建议、训练计划制定、训练记录、训练计划修改、身体数据分析。
2. 不支持问题必须进入 `UNSUPPORTED`，回复支持范围和建议问法，不展开回答。
3. 饮食、训练、计划、身体数据、用户画像写入必须先生成 `pendingWrite`。
4. 只有当前 session 最新且未过期的 `pendingWrite` 可以被“确认”。
5. 没有 `pendingWrite` 时，用户说“确认”不能触发任何写入工具。
6. 训练记录不能调用饮食写工具，饮食记录不能调用训练写工具。
7. 图片识别必须显式调用 `vision.food.recognize` 或 `vision.bodyScale.ocr`。
8. `斤` 必须换算成 kg，例如 `115 斤 = 57.5 kg`。
9. 工具失败时不能回复“已完成 / 已记录 / 已保存”。
10. 错误、工具失败和不支持问题不得写入长期记忆。
